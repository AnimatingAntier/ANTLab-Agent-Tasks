## Lost in the Middle

[原文 v3](https://arxiv.org/html/2307.03172v3)，§2.1–2.3、§4、§5。

论文通过调整文档数量与含答案文档的位置研究上下文使用；原多文档问答设定包含一个答案文档。本题是七段中文模拟记录，可能需要跨段计算，也有资料不足。原研究的位置敏感性是本题提出假设的依据，不能作为所选现代模型必然出现 U 形的保证。§4 的任务间差异提示输入组织的作用依赖任务条件；§5 提示增加材料并非无条件改善回答。

实现决定：R0/R1/R2 严格保留各自顺序；主改进保留全文并只改变组织，避免把删掉证据与位置变化混为一谈。结果仅限八题配对观察。

## ALCE

[原论文](https://aclanthology.org/2023.emnlp-main.398.pdf)，§3.2–3.3（PDF物理第4–5页）、§6。

原文区分答案正确性与引用质量。§3.3 的 citation recall 检查陈述能否被所引资料整体支持，precision 检查无关引用；它使用 NLI 模型近似蕴含，本题不复刻该自动指标，也不把模型自评当金标准。

实现决定：自动程序只判断 JSON 与引用范围；语义支持、证据覆盖和合理拒答分别保留人工复核字段。答案碰巧一致而批次错误，不能被合并为全面正确。

依据题包阅读提要与本地 provider 计时位置，完整 API 请求耗时包含客户端可见的等待，不提供服务端排队、Prefill、Decode 或 GPU 型号证据。后续若研究性能机制，需要推理服务提供独立时间戳及负载字段。
